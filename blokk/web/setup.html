Reading the hardware…

Sized for five workers at 40k context each. Your ceiling is cache, not model size — the kv column is what fills the machine, and it grows with workers and context, not with the weights.

Which model

One is enough to start. Two tiers is a real optimisation — most agent work is triage and does not need a big model — but it is a second server to keep alive, so reach for it once you have measured your own mix.

Backends

Blokk speaks the OpenAI API, so llama.cpp and MLX are just ports — it can run both at once, one per tier. Here is what it picked and why.

A suggestion, not a verdict — the numbers behind it were measured on other people's Macs. Once running, bench.py --compare settles it on yours.
